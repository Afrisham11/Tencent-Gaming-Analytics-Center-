# Tencent-Gaming-Analytics-Center-


##  Overview

The **Tencent Gaming Analytics Center** is an interactive Power BI dashboard designed to analyze gaming performance, player engagement, revenue, and regional activity. It provides valuable insights into player behavior, in-app purchases, game popularity, and business performance through a modern executive dashboard.

---

##  Dashboard Features

### Key Performance Indicators (KPIs)

- Average Retention Rate
- Average Session Duration
- Average Game Rating
- Monthly Active Users (MAU)
- Daily Active Users (DAU)
- Total Revenue

---

###  Interactive Filters

- Country
- Game
- Region

---

### Visualizations

- Revenue by Country (Map)
- Revenue by Platform
- Purchases by Region
- Retention Rate by Game
- Monthly Active Users Trend
- Revenue by Genre (Treemap)

---

##  Business Insights

This dashboard helps answer questions such as:

- Which countries generate the highest gaming revenue?
- Which game genres perform the best?
- How are Monthly Active Users changing over time?
- Which platform generates more revenue?
- Which region has the highest purchase activity?
- Which games have the highest player retention?

---

##  Tools Used

- Power BI Desktop
- Power Query
- DAX
- Azure Maps

---

##  Dataset

The dashboard is built using a realistic gaming analytics dataset containing:

- Game Information
- Player Activity
- Revenue
- In-App Purchases
- Session Duration
- Ratings
- Platform
- Region
- Country
- Monthly & Daily Active Users

---

##  Dashboard Purpose

The objective of this dashboard is to monitor gaming performance, evaluate player engagement, analyze revenue trends, and support strategic decision-making using interactive business intelligence visualizations
